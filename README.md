# 💸 GX Smart Pocket

> **Snap a receipt. Master your money.**

GX Smart Pocket is an AI-powered financial coach that turns every receipt into a financial insight — helping students and first-time earners build real saving habits, automatically.

🔗 **Live Prototype:** [https://gxsmartpocket.lovable.app](https://gxsmartpocket.lovable.app)

---

## 🧩 The Problem

Young Malaysians are flying blind financially.

- **68%** of young adults live paycheck to paycheck with no clear idea where their money went
- **3 in 4** have no savings habits — existing apps are too complex, manual, or built for Western spending patterns
- **92%** fail their savings goals without a system that automates the discipline daily

---

## 💡 Our Solution

GX Smart Pocket combines receipt scanning, smart categorisation, savings automation, and AI coaching — all without requiring you to manually enter a single number.

| Feature | Description |
|---|---|
| 📸 **AI Receipt OCR** | Snap any receipt — AI extracts every item, price, and category instantly |
| 🤖 **AI Habit Coach** | Personalised weekly insights that flag overspending and celebrate savings wins |
| 🎯 **Goal Pockets** | Set a savings goal, AI suggests a daily save amount, auto-save runs at 11:59 PM nightly |
| 🌳 **Savings Tree & Streaks** | Gamified tree that grows with your streak — sunny when on track, stormy when overspending |
| 🤝 **Bill Splitting** | Split receipts with friends by email, track IOUs, and settle with one tap |
| 💰 **Smart Dashboard** | Live balance, daily spend progress, category breakdown — all in real time |

## 🏗️ Technology Stack

```
Frontend        React 19 · TypeScript · TailwindCSS 4 · TanStack Router · Recharts · Radix UI
Backend         Supabase · PostgreSQL · Edge Functions · Row-Level Security · Realtime
AI              OpenAI Vision API · Receipt OCR · Habit Insight Generation
Deployment      Cloudflare Workers · Vite 7 · Bun runtime
```

**Architecture:** Client-server with Supabase as the backend-as-a-service layer. All AI processing runs in Supabase Edge Functions. Real-time bill-split updates use Supabase Realtime channels. Row-Level Security ensures every user sees only their own data.
